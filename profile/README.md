## What is Core Temp?

Core Temp is a compact, lightweight, and high-accuracy hardware diagnostic utility designed for real-time central processing unit (CPU) temperature monitoring and thermal telemetry tracking. Built for system administrators, overclockers, hardware enthusiasts, and IT service engineers, the software collects live thermal metrics directly from internal processor sensor interfaces.

Operating independently of motherboard-based thermal sensors, Core Temp reads data straight from the Digital Thermal Sensors (DTS) embedded within each individual processing core. This architecture allows the application to deliver precise, real-time per-core temperature metrics alongside key operational variables, including core frequency, CPU load, supply voltage (VID), thermal design power (TDP), and Junction Max (TJMax) thresholds.

Engineered specifically for modern and legacy Windows desktop environments, Core Temp features an automated **Overheat Protection** engine, continuous background log file creation, and system tray notification area telemetry displays. Whether stress-testing hardware configurations, diagnosing cooling system degradation, or monitoring field deployment thermals, the utility provides a zero-bloat environment for processor diagnostics.

### 🎛 Key Features

| Feature | Description |
|---------|-------------|
| **Digital Thermal Sensor (DTS) Reading** | Direct interface with CPU DTS hardware for highly accurate, per-core temperature measurement. |
| **Comprehensive CPU Telemetry** | Displays real-time core frequencies, processor load percentage, supply voltage (VID), and TJMax limits. |
| **Automated Overheat Protection** | Triggers visual alerts, pops up notification balloons, or shuts down/sleeps the system upon hitting user-defined temperatures. |
| **System Tray Telemetry Display** | Live customizable taskbar notification tray icons reflecting individual core thermal metrics in real time. |
| **Data Logging & Export** | Records ongoing processor metrics into CSV log files for long-term thermal analysis and hardware stress auditing. |
| **Extensible Plugin System** | Supports developer add-ons and plugins to pass telemetry metrics to remote dashboards or external hardware displays. |
